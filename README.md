# 请雇我工作岛 · 3D 作品集

一个用三维小岛做导航的个人作品集。岛上分布着几个展馆，点进去可以读项目介绍、直接体验作品，或者翻简历和问答。

在线使用：https://xueer03135998-creator.github.io/3d-island-site/

## 岛上有什么

食堂小屋放的是「午餐小助手」，占卜馆放的是「梅花易数 / 小六壬」，两个作品都能在页面里直接打开体验，链接指向各自独立的项目站点。非遗体验馆是《木偶·归途》，一段关于布袋木偶戏的互动叙事，以内嵌页面呈现，手机竖屏效果更好。个人档案馆是简历，含基本信息、实习经历、技能与荣誉和联系方式，另有一组可检索的问答，回答关于项目与经历的提问。

## 仓库里有什么

`index.html` 是作品集主页面，三维场景由 three.js 在浏览器里绘制，代码和样式都已内联，约 1.2 MB。`models/usagi.glb` 是岛上的模型文件。`heritage/index.html` 是非遗互动故事页，同样自包含，约 1.1 MB。`.nojekyll` 让 GitHub Pages 跳过 Jekyll 处理。

页面之间用相对路径互相引用，路由走 hash，放在项目子路径下也能正常工作。除作品卡片里指向的两个外部站点外，页面不请求其他服务器，也没有后端。

这个仓库只放构建产物，不含源码。

## 部署

GitHub Pages 发布 main 分支根目录，push 后自动重建，链接不变。
